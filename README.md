# 🏭 Procurement Control Tower
### Analytics & Process Automation — PrimeHarvest Foods Brasil

> Case de portfólio ponta a ponta que simula uma solução corporativa de analytics e automação para a área de Procurement, com foco em qualidade de dados, visibilidade de custos e suporte à decisão estratégica.

---

## 📌 Visão Geral

**Procurement Control Tower** é um case de analytics desenvolvido para uma empresa fictícia do setor alimentício — a **PrimeHarvest Foods Brasil** — que atua em categorias como molhos, condimentos, vegetais processados, embalagens e logística.

O projeto cobre o ciclo completo de uma solução de dados: desde a extração e consolidação via SQL, passando por automação de processos, até a entrega de um dashboard executivo com storytelling orientado a decisão.

---

## 🎯 Objetivo do Projeto

Demonstrar uma abordagem sênior de BI e automação aplicada ao contexto de Procurement, com ênfase em:

- rastreabilidade e confiabilidade dos dados
- modelagem analítica orientada a negócio
- automação de rotinas operacionais
- comunicação executiva com foco em risco e oportunidade

## 🧱 Stack Tecnológica Simulada

Este projeto utiliza uma stack corporativa simulada, representativa de ambientes de analytics para Procurement:

| Camada | Tecnologia | Finalidade |
|---|---|---|
| Extração & Transformação | SQL Server | Joins, consolidação, marts analíticos |
| Controle Operacional | Excel + VBA | Templates de entrada e pré-processamento |
| Automação de Processos | Power Automate | Workflows, validação e alertas |
| Visualização | Power BI (conceitual) | Modelagem analítica e design de dashboard |
| Protótipo Interativo | HTML / CSS / JavaScript | Simulação visual próxima ao Power BI |

---

## 📊 Módulos Principais

### 1. Camada de Dados (SQL)
- Extração e joins de ordens de compra, fornecedores e categorias
- Criação de marts analíticos para consumo no dashboard
- Checkpoints de reconciliação e governança de qualidade

### 2. Automação de Processos (Power Automate + VBA)
- Orquestração de workflows de atualização
- Validação de entradas e tratamento de exceções
- Alertas automáticos para desvios de SLA e custo

### 3. Dashboard Executivo (Power BI / Protótipo HTML)
- KPIs de Procurement: volume, custo, prazo e qualidade de fornecedores
- Análise de risco por fornecedor e categoria
- Storytelling executivo com framing de oportunidades de negociação
- Sinais de mercado integrados para contexto de custo

## 💼 Valor de Negócio

A solução foi projetada para gerar impacto direto em:

- **Eficiência operacional** — redução do esforço manual em reporting
- **Confiabilidade** — rastreabilidade e consistência dos dados de ponta a ponta
- **Velocidade de resposta** — acesso rápido a insights para compradores e gestores de categoria
- **Inteligência estratégica** — benchmarks de custo e identificação de oportunidades de negociação
- **Gestão de risco** — visibilidade de fornecedores críticos e dependências de categoria
- **Tomada de decisão** — storytelling executivo estruturado para liderança
